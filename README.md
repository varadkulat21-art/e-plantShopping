# e-plantShopping

**Paradise Nursery** is a React plant-shopping application for browsing houseplants, adding plants to a Redux-powered cart, changing quantities, and reviewing the total before checkout.

## Features
- Landing page with “Welcome To Paradise Nursery” and a “Get Started” button
- About Us page section
- Three plant categories with six plants in each category
- Plant thumbnails, names, prices, and Add to Cart buttons
- Redux Toolkit cart state with `addItem`, `removeItem`, and `updateQuantity` reducers
- Dynamic cart quantity, line totals, and grand total
- Increment, decrement, delete, checkout, and continue-shopping controls
- Responsive layout

## Run locally
1. Install Node.js (18 or later).
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.

## GitHub submission
Create a **public** GitHub repository named exactly `e-plantShopping`, upload the project files, and use the public `blob/main/...` URL for each requested file. Ensure the repository's default branch is `main`.
